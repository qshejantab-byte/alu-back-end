# alu-back-end

This project is about using a REST API with Python.
I used the JSONPlaceholder API to get information about
employees and their TODO lists.

## Files (in the api folder)

* 0-gather_data_from_an_API.py - prints the TODO progress of an employee
* 1-export_to_CSV.py - saves the tasks of an employee in a CSV file
* 2-export_to_JSON.py - saves the tasks of an employee in a JSON file
* 3-dictionary_of_list_of_dictionaries.py - saves the tasks of all
  employees in one JSON file

## How to use

./0-gather_data_from_an_API.py 2
./1-export_to_CSV.py 2
./2-export_to_JSON.py 2
./3-dictionary_of_list_of_dictionaries.py

The number is the employee id.
